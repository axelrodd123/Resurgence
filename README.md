## What it is

Resurgence is a focused, premium toolkit that surfaces the procs, cooldowns, and combat moments that matter to your gameplay. Every module is hand-built on the new 12.0.x safe APIs. Nothing tainted, nothing legacy, nothing in the way.

This early build is the visual shell : a circular launcher on your screen, an in-game menu with a full roadmap, and the brand foundation. The engine and curated content arrive in `v0.3`.

## Commands

| Command | Description |
|---|---|
| `/res` or `/resurgence` | Toggle the main menu |
| `/res show` / `/res hide` | Toggle the on-screen launcher button |
| `/res welcome` | Replay the welcome popup |
| `/res roadmap` / `about` / `settings` / `support` | Jump to a specific tab |
| `/res reset` | Reset launcher and window positions |
| `/res help` | Show the full command list |
